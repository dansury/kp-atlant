# Constitution — Atlant Armour КП Automation

## Non-negotiable principles

### I. Менеджер — последнее слово
Система ПРЕДЛАГАЕТ, менеджер ПОДТВЕРЖДАЕТ. Ни одно КП и ни одно письмо не уходит клиенту без явного нажатия кнопки менеджером. Автоматизация убирает рутину, а не заменяет человеческое решение.

### II. Данные МойСклад — единственный источник правды о товарах
Цены, остатки, характеристики, статусы резерва — всё берётся из МойСклад через API. Локальные кеши допустимы для скорости, но обновляются при каждом формировании КП.

### III. Тон и стиль — из GRAPH (ToV)
Любой автогенерируемый текст (сопроводительное письмо, комментарий в КП, письмо допродажи) проходит через правила ToV Atlant Armour. Без пафоса, с цифрами, полевой язык.

### IV. Накопление контекста — не опция, а архитектурный принцип
Каждая корректура менеджера сохраняется и влияет на будущие генерации. База знаний растёт с каждым обработанным запросом. Система становится лучше со временем.

### V. Безопасность учётных данных
Токены API, пароли SMTP, ключи нейросетей хранятся в серверных переменных окружения или зашифрованном хранилище. Никогда не попадают в фронтенд, логи или Git.

### VI. PDF — брендированный документ
КП всегда содержит логотип Atlant Armour, реквизиты юрлица (настраиваемые), таблицу товаров, условия и подпись. Минимализм, стиль, вкус — в лучших традициях российского B2B.

### VII. Один стек, простой деплой
PHP + SQLite + vanilla JS. Без тяжёлых фреймворков. Деплоится на любой shared-хостинг с PHP 8.1+. LLM-вызовы через OpenRouter и/или Yandex Foundation Models — инфраструктура из NeuroPro.

### VIII. Юрлицо настраивается
Реквизиты отправителя (ИП / ООО, ИНН, ОГРНИП, подпись, город) меняются из интерфейса настроек, а не в коде.
